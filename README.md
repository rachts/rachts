## 🚀 Featured Projects

### 🎙️ [Vocalis OS](https://github.com/rachts/Vocalis) — Agentic AI Voice Assistant
&gt; A voice-first AI system with real-time speech recognition, LLM reasoning, tool calling, and persistent memory.

`Next.js` `TypeScript` `Express.js` `Gemini API` `WebSockets` `Deepgram` `ElevenLabs`

- Built an **agentic orchestration layer** where LLMs dynamically select tools (web search, calendar, tasks) from natural language
- Features real-time streaming, conversational memory, and modular plugin architecture

---

### 💊 [Vitamend](https://vitamend.vercel.app) — AI Medicine Donation Platform
&gt; OCR + AI-powered platform reducing medicine wastage by automating verification for donors and NGOs.

`Next.js` `TypeScript` `MongoDB` `FastAPI` `OpenCV` `Pytesseract` `Gemini API`

- 🌐 [Live Demo](https://vitamend.vercel.app) · [Repository](https://github.com/rachts/vitamend)
- Automated **medicine verification pipeline**: OCR extraction → AI validation → expiry checking → QR validation
- End-to-end full-stack: Computer Vision backend + React frontend + database architecture

---

### 📰 [Kred.ai](https://github.com/rachts/kred-ai) — AI News Verification
&gt; Evidence-backed claim analysis using live web search, retrieval systems, and LLM reasoning.

`Next.js` `TypeScript` `Gemini API` `Serper API` `Tailwind CSS`

- [Repository](https://github.com/rachts/kred-ai)
- Implements **Retrieval-Augmented Generation (RAG)** with live evidence grounding instead of hallucinated responses
- Multilingual support with confidence scoring and structured citation reports
