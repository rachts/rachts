# 🚀 Featured Projects

## 🎙️ Vocalis OS

**Agentic AI Voice Assistant**

Vocalis is a voice-first AI assistant designed for natural-language interaction with software tools.

Instead of relying solely on predefined commands, the system uses an **LLM-driven orchestration layer** to interpret user requests and determine which tools or workflows should be executed.

**Key Engineering Work**

* 🎤 Real-time speech recognition
* 🧠 LLM-based intent understanding and planning
* 🔌 Tool/plugin architecture
* 🌐 Web search integration
* 📅 Calendar and reminder workflows
* ✅ Task automation
* 💬 Conversational memory
* ⚡ Streaming and real-time communication

**Stack:** `Next.js` `React` `TypeScript` `Express.js` `Gemini` `WebSockets` `Deepgram` `ElevenLabs`

**Repository:**
https://github.com/rachts/Vocalis

## 💊 Vitamend

**AI-Assisted Medicine Donation & Verification Platform**

Vitamend combines **Computer Vision, OCR, AI reasoning, and full-stack development** to assist with medicine verification and donation workflows.

**Key Engineering Work**

* 📷 OCR-based medicine information extraction
* 🤖 AI-assisted medicine verification
* 📅 Expiry-date extraction and validation
* 📦 Batch and QR-code validation
* 🖼️ Image-based medicine analysis
* 📍 Donation-center discovery
* 📊 Donation workflow and analytics

**Pipeline**

```text
Medicine Image
      ↓
OCR / Image Processing
      ↓
Information Extraction
      ↓
AI Verification
      ↓
Expiry & Batch Validation
      ↓
Donation Workflow
```

**Stack:** `Next.js` `React` `TypeScript` `MongoDB` `FastAPI` `OpenCV` `Pytesseract` `Gemini`

**Live:** https://vitamend.vercel.app
**Repository:** https://github.com/rachts/vitamend

## 📰 Kred.ai

**AI-Powered News & Claim Verification**

Kred.ai combines live web search, evidence retrieval, and LLM reasoning to analyze potentially misleading claims.

The system focuses on **grounding AI-generated conclusions in retrieved evidence** rather than relying exclusively on model knowledge.

**Key Engineering Work**

* 🌐 Live web search
* 🔎 Evidence retrieval
* 🤖 LLM-based claim analysis
* 📊 Confidence assessment
* 🌍 Multilingual analysis
* 📚 Evidence-oriented verification reports

**Pipeline**

```text
Claim / News
     ↓
Web Search
     ↓
Evidence Retrieval
     ↓
Evidence Processing
     ↓
LLM Analysis
     ↓
Confidence Assessment
     ↓
Verification Report
```

**Stack:** `Next.js` `TypeScript` `Gemini` `Serper` `Tailwind CSS`

**Repository:**
https://github.com/rachts/kred-ai

## 🔐 PrivSight

**Computer Vision-Based Desktop Privacy System**

PrivSight explores automated screen privacy using real-time Computer Vision.

The application detects people around the user's workspace and can trigger privacy protection when an unauthorized viewer is detected.

**Stack:** `Electron` `React` `Python` `OpenCV` `WebSockets`

**Repository:**
https://github.com/rachts/privsight
